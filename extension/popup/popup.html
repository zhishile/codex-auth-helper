该文件不能长期使用

网页会话无法生成 refresh_token——它只能由 auth.openai.com 的 OAuth 流程签发。 因此本文件仅临时可用，Codex 刷新时会提示 Your access token could not be refreshed。 请用下面任一方式完成官方登录：

  1. 导入本文件后，在 Codex 客户端里退出登录 → 重新登录（保留 auth.json，不要删除）
  2. 或执行 codex login / codex login --device-auth
  3. ChatGPT → Settings → Security 配置 Passkey / Authenticator，用 Try another method 代替短信

完整说明见仓库 README 的「已知限制与可用方案」。

使用步骤提示
1
第一步：导出身份信息

点击上方“导出身份信息”按钮，系统将自动把您本地的 ChatGPT 身份验证数据导出并下载保存为 auth.json 文件。

2
第二步：将身份信息拷贝或移动到Codex配置目录

将 auth.json 移动到本机 Codex 配置目录中：

Windows: %USERPROFILE%\.codex\auth.json

macOS: ~/.codex/auth.json

3
第三步：启动 Codex 并完成官方登录

启动或重启 Codex 客户端。若提示 Your access token could not be refreshed，请保留 auth.json 不要删除，在客户端里点“退出登录”后重新登录——此时会走官方 OAuth 流程，多数付费账号不再要求手机短信验证。
